# Ecclesia language examples

A small tour of Ecclesia's modern source syntax.

**Important:** These files illustrate capabilities in the active development version. The public repository does not currently ship a verified compiler binary or full build system, so the examples cannot be run using this checkout alone.

| Example | Topic |
| --- | --- |
| [hello.ecs](hello.ecs) | Printing and an entry point |
| [functions.ecs](functions.ecs) | Typed functions and a loop |
| [arrays.ecs](arrays.ecs) | Fixed-length arrays and indexed assignment |

These examples are kept intentionally approachable. They do not replace compiler regression tests or formal qualification evidence. Future public source releases should run them in CI before making an executable compatibility claim.

Unlike the original R0 program set, these examples represent later language additions; this is intentional. Older R0 documentation is a historical record, not the present syntax ceiling.
